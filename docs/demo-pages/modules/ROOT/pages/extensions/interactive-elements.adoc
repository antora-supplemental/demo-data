.Keyboard Shortcuts
The `kbd` macro renders keyboard shortcuts.
These typically style well in dark mode.
****

Press kbd:[Ctrl+Shift+P] to open the command palette.

Use kbd:[Cmd+K] then kbd:[Cmd+S] to save all files.

Common shortcuts: kbd:[Esc], kbd:[Enter], kbd:[Tab], kbd:[Space]

****
.Menu & Button UI Macros
Menu selections and button references help document GUIs.
****

Select menu:File[Save As... > PDF] to export.

Click btn:[OK] to confirm or btn:[Cancel] to abort.

Navigate to menu:Settings[Appearance > Theme > Dark].
