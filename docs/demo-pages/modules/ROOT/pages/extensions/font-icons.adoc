****
.Font Awesome Icons
When `:icons: font` is set, AsciiDoc renders icons via Font Awesome.
These inherit text color automatically.
****

icon:heart[role=red] Love this theme

icon:code[] Write some code

icon:sun-o[] Light mode / icon:moon-o[] Dark mode

icon:github[] Check out the repo

icon:warning[] Warnings stand out
