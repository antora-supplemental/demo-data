= Antora body fixtures
:navtitle: Demo home
:description: Host-agnostic AsciiDoc pages that exercise default Antora rendering and theme chrome (Valentus, Default UI, etc.).
:page-tags: demo, fixtures, asciidoc

These pages showcase common AsciiDoc constructs in a real multi-page component: navigation, xrefs, admonitions, tables, code, images, and extension-oriented samples.

TIP: On Valentus-backed demos, use the *theme toggle* in the navbar to compare light and dark modes.
