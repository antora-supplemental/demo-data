= Extension supplements (`docs/fixtures/`)

Each subdirectory holds one **shared** fixture set promoted from extension repos when two or more demos need the same Antora content.

Playbooks add a separate `content.sources` entry per supplement `start_path`. Baseline body pages stay in the `demo-pages` component at link:../../README.adoc[docs/demo-pages] (see repo README).

| `start_path` | Extension | Notes |
| === | === | === |
| link:site-nav-tree/README.adoc[site-nav-tree] | `@antora-supplemental/site-nav-tree` | `catalog-alpha`, `catalog-beta` multi-root forest |

Authority for naming and when to promote fixtures: link:../../README.adoc[demo-data README] · link:https://docs.antora-supplemental.org/docs/proposals/demo-data-catalog/[Demo data catalog^].
