== Playbook wiring

Add one `content.sources` entry per component (`catalog-alpha`, `catalog-beta`) — each subdirectory has its own `antora.yml`.
Enable `@antora-supplemental/site-nav-tree` with an explicit `include` list that keeps **`demo-pages`** (and your hub component) as forest roots — do **not** add `catalog-alpha` / `catalog-beta` to `include` when you want them nested under baseline nav.

Set AsciiDoc attribute `demo-fixtures-site-nav-tree` so `demo-pages` nav includes xrefs to these components under *Extensions*.

[source,yaml]
----
content:
  sources:
    - url: https://github.com/antora-supplemental/demo-data.git
      tags: [v0.3.2]
      branches: []
      start_path: docs/demo-pages
    - url: https://github.com/antora-supplemental/demo-data.git
      tags: [v0.3.2]
      branches: []
      start_path: docs/fixtures/site-nav-tree/catalog-alpha
    - url: https://github.com/antora-supplemental/demo-data.git
      tags: [v0.3.2]
      branches: []
      start_path: docs/fixtures/site-nav-tree/catalog-beta

asciidoc:
  attributes:
    demo-fixtures-site-nav-tree: ''

antora:
  extensions:
    - require: '@antora-supplemental/site-nav-tree'
      include: [home, demo-pages]
      order: [home, demo-pages]
----

The `facto-stack` demo enables this forest smoke by default; see link:https://github.com/antora-supplemental/facto-stack[`facto-stack`^] `demo/playbook.yml`.
