== Playbook wiring

Add a second (or third) content source pointing at this folder.
Enable `@antora-supplemental/site-nav-tree` with an explicit `include` list.

[source,yaml]
----
content:
  sources:
    - url: https://github.com/antora-supplemental/demo-data.git
      branches: main
      start_path: docs/theme-demo
    - url: https://github.com/antora-supplemental/demo-data.git
      branches: main
      start_path: docs/fixtures/site-nav-tree

antora:
  extensions:
    - require: '@antora-supplemental/site-nav-tree'
      include: [catalog-alpha, catalog-beta]
      order: [catalog-alpha, catalog-beta]
----
